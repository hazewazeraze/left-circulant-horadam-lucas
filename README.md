# Left circulant matrices: Horadam and alternating-sign Lucas sequences

Reproducibility materials for the revised manuscript **“Determinant, Inverse, and Spectrum of Left Circulant Matrices Generated by Horadam Sequences, with Application to the Alternating-Sign Lucas Sequence”** (MJMS-2026-0493).

## Repository contents

- `code/`: matrix and sequence routines, Fourier-based methods, exact validation, benchmarks, figure generation and the FTZ/DAZ control experiment.
- `data/publication/`: recorded timing results, per-session statistics, validation tables, figure source data and experiment metadata (14 CSV and two JSON files).
- `figures/`: the five PDF figures accompanying the manuscript.
- `requirements.txt`: Python package versions used for the numerical experiments.

## Reproducing the figures

From the repository root:

```bash
python -m pip install -r requirements.txt
python code/02_generate_figures.py --data data/publication --output figures
```

This command reconstructs the figures from the archived data. It does not rerun the benchmarks.

## Validating the numerical results

To keep the original timing data and regenerate the exact determinant, Horadam and condition-number checks in a separate directory:

```bash
python code/01_generate_table_data.py --reuse-results data/publication --output data/reproduced
```

For a new benchmark on the current machine:

```bash
python code/01_generate_table_data.py --output data/new_run
```

Use `--quick` to limit benchmark orders to 10, 50 and 100. Full exact verification can take substantially longer. Repeated benchmarks are expected to differ across hardware and software environments.

## Subnormal-arithmetic experiment

On Windows:

```bash
python code/03_subnormal_check.py --output data/subnormal_reproduced
```

On Linux x86-64:

```bash
gcc -O2 -shared -fPIC -msse2 -o libftz.so code/ftz.c
python code/03_subnormal_check.py --lib ./libftz.so --output data/subnormal_reproduced
```

The C helper changes the FTZ/DAZ state of the current thread. This control experiment depends on the CPU architecture and runtime implementation.

## Reproducibility notes

Run the scripts from the repository root. Use `python code/04_check_environment.py` to inspect the current Python environment and loaded BLAS libraries.

`benchmark_metadata.json` records the archived single-thread Windows benchmark and lists two loaded OpenBLAS runtimes. `timing_sessions.csv` contains session-level summaries, not every individual timing sample. The published timing data and validation results have been retained without modification; no independent Linux benchmark dataset is included.
